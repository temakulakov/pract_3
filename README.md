# Практическая работа №3 — сайт на 1С-Битрикс

Кулаков Артем, группа Пи2у/23Б.

1С-Битрикс: Управление сайтом, редакция «Бизнес». На сайте `s1` установлено решение «Интернет-магазин» (одежда). Второй сайт `s2` — персональная страница из первой практики, перенесенная на Битрикс.

- Магазин: https://pract3.temakulakov.ru
- Персональный сайт: https://pract3.temakulakov.ru/kulakov/

## Что сделано

- сайт `s2` в папке `/kulakov/` с шаблоном `kulakov_theme` (верстка из pract_1);
- компоненты `kulakov:personal.about`, `personal.skills`, `personal.projects`, `personal.gallery`, `personal.socials`, `personal.contact`, `personal.certificates`, `site.about`;
- инфоблоки типа «Персональный сайт»: обо мне, навыки, проекты, галерея, соцсети, сертификаты, о сайте;
- страница «Сертификаты»: превью из инфоблока, просмотр на весь экран, скачивание PDF и изображения;
- тип инфоблоков «Тестовый» (`test`): «Авторы» (`test_authors`) и «Статьи» (`test_article`), автор (Кулаков Артем Андреевич), раздел «Статьи о 1С-Битрикс: Управление сайтом» и две статьи;
- страницы «Статьи» и «Авторы»: статический текст и компонент `bitrix:news` со своим шаблоном;
- страница в админке «Настройки → Настройки сайта (Kulakov)» для ФИО и группы в боковом меню (`local/admin/`).

Весь свой код лежит в `www/local/` (шаблон, компоненты, `init.php`, страница админки), публичные страницы сайта — в `www/kulakov/`, наполнение инфоблоков — `setup/`. Ядро Битрикса, файлы магазина, `upload/` и база в репозиторий не входят.

## Запуск

Нужен Docker.

```bash
git clone https://github.com/temakulakov/pract_3.git
cd pract_3
docker compose up -d --build
```

1. В `www/` распаковать дистрибутив «1С-Битрикс: Управление сайтом — Бизнес» и пройти установку на http://localhost:8081 (сервер БД `db`, база `bitrix`, пользователь `bitrix`, пароль `bitrix123`), решение — «Интернет-магазин».
2. Создать сайт `s2` и инфоблоки:

```bash
docker cp setup bitrix_web:/tmp/setup
docker compose exec -u www-data web php /tmp/setup/setup.php
```

Скрипт выводит ID инфоблоков — их нужно указать в параметрах компонентов на страницах в `www/kulakov/`, если они отличаются.
