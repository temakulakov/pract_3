# Практическая работа №3 — сайт на 1С-Битрикс

Кулаков Артем, группа Пи2у/23Б.

Персональная страница из первой практики, перенесенная на 1С-Битрикс: Управление сайтом. Содержимое страниц хранится в инфоблоках, для вывода написаны свои компоненты и шаблон.

Сайт: https://pract3.temakulakov.ru

## Что сделано

- шаблон сайта `kulakov_theme` (верстка из pract_1);
- компоненты `kulakov:personal.about`, `personal.skills`, `personal.projects`, `personal.gallery`, `personal.socials`, `personal.contact`, `site.about`;
- инфоблоки: обо мне, навыки, проекты, галерея, соцсети, о сайте;
- страница в админке «Настройки → Настройки сайта (Kulakov)» для ФИО и группы в боковом меню;
- своя страница 404.

Код лежит в `www/local/` и в файлах страниц в `www/`. Ядро Битрикса, `upload/` и база в репозиторий не входят.

## Запуск

Нужен Docker.

```bash
git clone https://github.com/temakulakov/pract_3.git
cd pract_3
docker compose up -d --build
```

Дальше в `www/` распаковать дистрибутив 1С-Битрикс и пройти установку на http://localhost:8081. Данные для подключения к базе: сервер `db`, база `bitrix`, пользователь `bitrix`, пароль `bitrix123`.

После установки назначить сайту шаблон `kulakov_theme`, создать инфоблоки и указать их ID в параметрах компонентов на страницах.
